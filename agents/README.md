# הסוכנים שלי

כל קובץ כאן הוא **הוראות לסוכן**. ככה מפעילים אותו:

1. נכנסים ל-claude.ai ← **Projects** ← **Create project**
2. נותנים שם (למשל "סוכן חנות השעונים")
3. מעתיקים את כל התוכן של הקובץ לשדה **Project instructions**
4. (רשות) מעלים ל-**Project knowledge** קבצים רלוונטיים: מחירון, תמונות, קטלוג
5. מדברים איתו כמו עם עובד

| סוכן | קובץ | בשביל מה |
|------|------|----------|
| 🕰️ חנות השעונים | `01-watch-store.md` | תיאורי מוצרים, תשובות ללקוחות, ניהול החנות ב-Wix |
| 📱 תוכן לרשתות | `02-social-content.md` | פוסטים, רילס, עיצובים ב-Canva, תזמון |
| 💰 כסף וחובות | `03-money-debts.md` | מעקב משמרות, חובות, חיסכון, סיכום שבועי |
| 🎯 פוקוס | `04-focus-manager.md` | לבחור פרויקט אחד ולסיים אותו |

> לפני השימוש מחליפים את כל מה שכתוב בתוך [סוגריים מרובעים] בפרטים האמיתיים.
