# הסוכנים שלי

## איך יוצרים סוכן (2 דקות לכל אחד)
1. נכנסים ל-claude.ai ← **Projects** ← **Create project**
2. נותנים שם (מופיע בטבלה למטה)
3. מעתיקים **את כל התוכן** של הקובץ לשדה **Project instructions**
4. (רשות) מעלים ל-**Project knowledge** את `catalog/paradise-watch-catalog.md` ותמונות של השעונים
5. שומרים, ומתחילים לדבר

| שם הפרויקט | קובץ | בשביל מה |
|---|---|---|
| 🕰️ סוכן חנות השעונים | `01-watch-store.md` | תשובות ללקוחות, תיאורים, מבצעים, Wix |
| 📱 סוכן תוכן | `02-social-content.md` | רילס, כיתובים, קמפיינים, משפיענים |
| 💰 סוכן כסף | `03-money-debts.md` | משמרות, חובות, רווח מהחנות |
| 🎯 סוכן פוקוס | `04-focus-manager.md` | "מה עכשיו?" וסיום פרויקטים |

**איך יודעים עם מי מדברים?** שם הפרויקט מופיע למעלה בצ'אט. בלי שם, זה Claude רגיל.

**שימו לב:** הסוכנים לא עובדים לבד ברקע ולא מדברים זה עם זה. כל אחד עונה רק כשכותבים לו.
